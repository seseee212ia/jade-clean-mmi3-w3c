# jade-clean-mmi3-w3c
Création d'un site web mobile de commandes de prestations de ménage professionnel, à destinatation d'hôtel haut de gamme, avec grilles de prestations, forfait et abonnement à l'année.
Deadline de livraison :Vendredi 23 Octobre 2026 avant 20h00 sur le FilleZilla

# Langages utilisés
* HTML5 : (Conformité W3C stricte)
* CSS3 : (Flexbox, Grid, Design System personnalisé - Mobile-First)
* JavaScript: (Vanilla: Interactivité, formulaires dynamiques, simulation de connexion)

# Équipe et Répartition des Tâches (Groupe W3C)
# Selma 
* Page d'Accueil (`index.html`) : Vitrine principale, en-tête, sections de présentation de la marque et accès rapides.
* Page de Connexion (`connexion.html`) : Interface d'authentification sécurisée pour les établissements hôteliers.
* Page Présentation (`presentation.html`) : Valeurs de l'entreprise, réassurance et positionnement luxe.

# Sofiia 
* Conditions Générales de Vente (`cgv.html`) : Cadre légal, mentions obligatoires et articles BtoB.
* Espace interne (espace admin)
* Page Compétences (`competences.html`) : Grilles de prestations détaillées et cartes de forfaits/abonnements annuels.

# Velon
* Page Contact (`contact.html`) : Formulaire de devis, coordonnées téléphoniques cliquables et validation JS.
* Page client (`client.html`) : Tableaux de bord dynamiques pour la gestion des plannings et le suivi des missions.
* Page avis client
