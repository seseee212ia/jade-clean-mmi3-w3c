# jade-clean-mmi3-w3c
Création d'un site web mobile de commandes de prestations de ménage professionnel, à destinatation d'hôtel haut de gamme, avec grilles de prestations, forfait et abonnement à l'année.
Deadline de livraison :Vendredi 6 Novembre 2026 avant 20h00 sur FilleZilla

# Langages utilisés
* HTML5 Sémantique
* Bootstrap 5: (Composants natifs, grille fluide, classes utilitaires responsives)
* CSS3: (Surcharge des styles pour respecter la charte graphique luxe - Bordeaux et fond sombre)
* JavaScript: (Vanilla : Interactivité des composants et dynamisme des formulaires)
